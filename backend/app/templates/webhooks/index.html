Webhooks

Receive event notifications at your own URL when money moves through your account.

How it works

When an event you're subscribed to fires, Orion sends an HTTP POST to your URL with a JSON payload signed with HMAC-SHA256.

1. Create a subscription
Provide a name + your receiver URL + select which events to listen for.
2. Save the secret
You'll get a signing secret — store it securely, you'll use it to verify the signature on incoming requests.
3. Verify signatures
X-Orion-Signature: sha256=... — recompute HMAC-SHA256 of the raw request body with your secret and compare.
4. Return 2xx
Any 2xx response marks the delivery as successful. 4xx disables retries; 5xx triggers retry (up to 3 attempts).
